# Chroma-Key Image Editing

A browser-based green-screen compositor built with HTML, CSS, and JavaScript. It demonstrates client-side chroma-key image processing and interactive editing without a backend.

## What it demonstrates

- Chroma-key / green-screen processing concepts
- Client-side JavaScript image manipulation
- Interactive browser UI
- A lightweight HTML/CSS/JavaScript project structure

## Run locally

Open `grnscr.html` in a modern browser.

```text
Image-Editing-using-Chroma-Key/
├── grnscr.html
├── greenscr.js
└── greenscreen.css
```

## Project status

An early computer-vision/web experiment retained as part of the project history. Newer AI/CV work on the profile contains more production-oriented systems.
